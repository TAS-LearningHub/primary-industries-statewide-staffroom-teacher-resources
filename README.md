# Primary Industries Teacher Resources

Local candidate for a teacher-only VET Statewide Staffroom navigator and source-aligned delivery program.

## Authority and boundary

- Authoritative source: the authenticated `Resources / Primary Industries` section in the [VET Statewide Staffroom](https://schoolsnsw.sharepoint.com/sites/VETstatewidestaffroom).
- Public pages may expose reviewed filenames, paths and stable authenticated pointers only.
- Do not copy controlled instruments, answers, learner evidence, private rubrics, personal information or controlled file contents into this repository.
- Staffroom links require departmental Microsoft 365 sign-in. Local and RTO decisions remain `Teacher/RTO to confirm`.

## Routes

- `index.html` — teacher landing page
- `program.html` — complete program and downloads
- `task.html?id=...` — task and source-program guides
- `library.html` — filtered direct-file library
- `sources.html` — source, privacy and assessment boundary

The shell is deliberately separate from the Primary Industries student site. Publication and the later student-site teacher link are gated on independent acceptance and live verification.
