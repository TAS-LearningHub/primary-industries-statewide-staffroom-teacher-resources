Authority · privacy · separation

What this site is—and what it deliberately is not.

A transparent boundary protects teachers, students, the RTO process and the separate Primary Industries student build.

Permitted authority

One authenticated source section

All course facts, teaching-program content and file metadata came from the signed-in VET Statewide Staffroom Resources / Primary Industries section, inspected on 2 September 2026.

  • The authenticated SharePoint index supplied 767 exact leaf-file paths across 162 folders, with formats, sizes and modification dates.
  • Twenty-two current 2026 Certificate II in Agriculture program templates were inspected for source structure and mapping.
  • A conservative review admitted 65 public-metadata-safe pointers: 30 current-2026 records, 27 AHCv9 references and 8 supporting resources. The other 702 inventory records remain outside the public layer.
  • The source register separates current, historical, controlled and review-required cues instead of treating every file as current teaching authority.
  • Direct URLs contain no Teams session identifiers or volatile authentication tokens.
  • Filename, task-number and unit-code inconsistencies remain visible rather than being silently corrected.

Public hosting boundary

This public site exposes only reviewed Staffroom filenames, folder paths and stable authenticated pointers. It copies no controlled file content. Opening a Staffroom resource still requires departmental Microsoft 365 sign-in.

Do not publish here: assessor answers, controlled instruments, learner evidence, private rubrics, personal information, controlled file contents or session-bound links.

Protected boundaries

Automatic stop lines

The banners separate authority controls from privacy and site-separation controls. Every card keeps a visible category label as well as its colour cue.

Separation

Visual scope

No invented photo quota

The source map sets a zero-photo target because this is a teacher navigator; decorative workplace imagery would not improve the job and could exceed source authority.

Known source decisions requiring local/RTO resolution: confirm the qualification, cohort, electives, delivery order, calendar and assessment versions; resolve the Task 3.6 filename / internal Task 6 title relationship; verify the Task 22 source-typed code “ACHLSK224”; and confirm local safety, supervision, facilities and evidence destinations. The complete program flags these decisions and does not invent corrections.
